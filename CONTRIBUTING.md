# Contributing

The Apinx source code is not public, so code contributions are not possible here. There is a
lot you can still do, and it is very welcome:

- **Report a bug** with the [bug report form](https://github.com/moznhub/apinx/issues/new/choose).
  A small API definition that shows the problem is the most useful thing you can send.
- **Ask for a feature** with the feature request form. Tell us the problem first; the solution
  can come later.
- **Help others** in [Discussions](https://github.com/moznhub/apinx/discussions).
- **Improve the examples.** Pull requests to `examples/` are welcome. They are under the MIT
  licence (see [LICENSE](LICENSE)).

Please follow the [code of conduct](CODE_OF_CONDUCT.md), and never paste API keys, tokens,
passwords or personal data in an issue.
