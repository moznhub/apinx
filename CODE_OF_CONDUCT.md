# Code of conduct

This is a place to get help with Apinx and to make it better. Be respectful, be patient with
newcomers, and assume good intent.

Not accepted here: harassment, insults, personal or political attacks, spam and advertising,
and publishing anyone's private information.

Maintainers may edit or remove content and block accounts that break these rules. To report a
problem, write to [support@moznhub.com](mailto:support@moznhub.com).
